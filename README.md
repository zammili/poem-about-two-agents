A [make.fun](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441) bounty entry: a short poem about agency — the power to choose and to act — when two agents agree on one plan.

`main.py` (Python 3.13, no network, no dependencies) writes the poem to `/output/entry.txt`: two minds arriving at one small switch, neither yielding, neither pulling rank, and the choice, made twice, becoming one act.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The program creates `/output` if needed and writes exactly the poem, nothing else. The poem is under 280 characters, as the competition requires.
